# LLM — The Eras Tour 🎤

Página interativa em HTML que explica o que é uma **LLM (Large Language Model)** inspirada nas eras musicais de **Taylor Swift**.

## Estrutura

Cada seção do documento é mapeada para uma era da Taylor Swift, com cores, estética e referências:

| Era | Tema LLM |
|---|---|
| 🟢 Taylor Swift (Debut) | Definição de LLM |
| 🟡 Fearless | Arquitetura Transformer |
| 🟣 Speak Now | Attention, Tokens, Parâmetros |
| 🔴 RED | Treinamento e custo computacional |
| 🔵 1989 | Linha do tempo da revolução |
| ⬛ reputation | Capacidades dos modelos |
| 🩷 Lover | Principais LLMs do mercado |
| 🤎 folklore | Aplicações reais |
| 🟤 evermore | Limitações |
| 🔵 Midnights | Exemplo prático |
| ⬜ The Tortured Poets Department | O futuro da IA |

## Como visualizar

Basta abrir o arquivo `llm.html` em qualquer navegador moderno.

## Tecnologias

- HTML5
- CSS3 (Gradientes, Grid, Flexbox, responsivo)
- Fontes: Playfair Display + Inter (Google Fonts)
